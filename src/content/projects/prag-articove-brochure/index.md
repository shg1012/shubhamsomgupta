## Overview

This one-month client project was completed for PRAG in 2017. As Design Consultant, I redesigned the graphics for **Articove**, an onboard water purifier for trains, and used the product's 3D model to create updated product and contextual renders.

The visual work was carried into a four-page A4 brochure. I prepared the production files and delivered the marketing collateral for print; the brochure was subsequently printed for PRAG.
