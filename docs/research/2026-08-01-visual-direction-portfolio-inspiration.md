# Visual-direction research: making the portfolio more distinctive without losing trust

**Reviewed:** 1 August 2026
**Purpose:** Identify visual patterns from public, first-party product/UX designer portfolios that can make Shubham S. Gupta's portfolio feel less uniformly corporate and more authored. This is inspiration research, not an instruction to copy another designer's layout, visual identity, claims, or imagery.

## Short answer

The current site already has motion, colour and polish. The more likely source of the “dull” feeling is **sameness**: a persistent dark/glass environment, similarly shaped cards, and a steady visual rhythm give every project roughly the same emotional temperature.

The strongest transferable direction is an **editorial field-notes portfolio**: use typography, photography, process artefacts, and category-specific visual worlds to make the work feel lived-in. Keep the information architecture and case-study evidence rigorous; make the *presentation* more expressive.

## Recommended visual changes

### 1. Replace the single glassy visual world with category-led “project atmospheres”

Use a stable core type scale and navigation, but allow a project/card to introduce one deliberate visual language rooted in the work:

- **Healthcare/service systems:** calm white or mist backgrounds, clinical blue-green, diagrammatic linework, measured spacing.
- **Industrial/product work:** warm off-white or charcoal, technical annotations, material close-ups, sharper geometry.
- **Brand/retail work:** bolder crop, colour blocking and identity fragments.
- **Photography:** edge-to-edge images with minimal labels.

This avoids redesigning every page while breaking the present all-dark, rounded-glass repetition. The distinction should be driven by actual project assets, not arbitrary colour themes.

### 2. Make the opening screen editorial rather than app-like

Use one oversized typographic gesture—such as the name, a short point of view, or a large wordmark—paired with one real image, sketch, or photographed object. Julian Vilela’s graphic name treatment and Amanda Sim’s personal opening show two ways a portfolio can establish an authorial voice before the work grid begins. [Julian Vilela](https://www.julianvilela.com/), [Amanda Sim](https://amandacsim.com/)

For Shubham, a suitable direction would be a large, confident headline with a compact “currently exploring” field-note label and a cropped Matterhorn/photography image. It should stay concise: recruiters should still see selected work without an extended scroll.

### 3. Recompose project cards as an asymmetric visual index

Avoid repeating one card anatomy everywhere. Keep title, role and proof line available, but vary the hierarchy across a 6–8 card section:

- one large, image-forward flagship;
- one tall “evidence tile” with a sketch, map, or prototype detail;
- one plain typographic project marker;
- one wide image sequence or before/after comparison;
- one restrained fact tile with a verified outcome or constraint.

Eleni Chasioti’s public project summaries make diverse artefacts explicit; that is a useful model for choosing source material rather than defaulting to screenshots. [Eleni Chasioti](https://echasioti.com/)

Nicole A. Roberts provides a second useful model: case-study previews can pair product imagery with a problem/outcome title, compact scope chips and an outcome numeral. Apply that hierarchy only where Shubham has a qualified, attributable metric; otherwise use a concrete project constraint or evidence label. [Nicole A. Roberts](https://www.nicolearoberts.com/)

### 4. Turn photography into a recurring rhythm, not an end-of-page appendix

The portfolio already contains original photography. Insert one photographic “breathing frame” between major work streams, or let an image crop become the background for a short statement about observation, systems, or craft. This makes the site feel personal without adding unsupported claims. Keep the gallery page, but use a few photographs as part of the main narrative.

### 5. Add a bounded `Field notes` / `Playground` section

Both Julian Vilela and Hendrik Pulst clearly separate client/selected work from playground or experiment content, and Ziyu He provides enough context to distinguish an exploratory artefact from live work. [Julian Vilela](https://www.julianvilela.com/), [Hendrik Pulst](https://hendrikpulst.com/), [Ziyu He](https://www.ziyu-he.com/)

For this portfolio, show 3–5 small items: a design-process sketch, typography/readability test, service-blueprint detail, physical prototype, or a photography study. Every item should carry a status label such as **concept**, **prototype**, **study**, or **shipped**. This is the safest way to become more playful while protecting credibility and confidentiality.

### 6. Use motion to reveal evidence, not as ambient decoration

Use a short hover/focus transition to expose a project’s artefact labels, or an optional click-controlled before/after, storyboard, or system-map sequence. The source portfolios’ experiment sections make interaction and craft concrete rather than merely atmospheric. [Hendrik Pulst](https://hendrikpulst.com/), [Ziyu He](https://www.ziyu-he.com/)

Respect `prefers-reduced-motion`, keep durations brief, and never hide key content behind hover. Avoid page-wide drifting effects competing with case-study material.

## A cohesive direction to prototype first

**“Evidence in the wild.”** A quiet editorial base—warm near-black or paper-white—interrupted by real artefacts at different scales: a field photograph, an annotated sketch, a system map, an interface crop and a physical-model image. Use one restrained accent colour per project, substantial image crops, and deliberately uneven grid proportions.

This would retain the existing site’s professional information design while shifting its personality from “generic premium dashboard” to “a designer’s working archive.”

## Additional visual-reference patterns

- [Daniella Marynova](https://hellodani.co/) uses an expressive typographic opening, a dense personal image collage and art-directed, two-image project previews. Borrow the **varied visual density**, not the composition itself: a small personal-photo strip and one strong project collage are enough.
- [Adham Dannaway](https://www.adhamdannaway.com/) makes positioning visual by presenting two labelled facets of his practice beside a portrait. A concise, evidence-backed dual framing—such as **systems thinking / experience craft**—could give Shubham’s hero more character if both sides are represented in selected work.
- [Chelsea Watson](https://www.chelseawatson.com/) adds personality through a conversational manifesto, role pillars and a personal experiment alongside serious work. This supports an intentional small “field notes” rail rather than filling the homepage with generic decorative effects.

## Guardrails

- Keep the first view immediately scannable: name, specialty, one concise value statement, and a visible route to selected work.
- Do not use abstract 3D, AI imagery, noisy grain, or motion simply to signal creativity. Prefer Shubham’s own process and photographic material.
- Preserve the distinction between concept/prototype/research and shipped outcomes in every label and caption.
- Maintain contrast, text over image legibility, keyboard visibility, and reduced-motion support.
- Prototype the new visual system on the homepage and one flagship case study before restyling every route.
